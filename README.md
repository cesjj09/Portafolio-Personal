# Portafolio digital — Juan Cervantes

Proyecto de ejemplo construido con HTML5, CSS3 y JavaScript.

## Estructura
- `index.html`: contenido y estructura semántica.
- `css/style.css`: estilos, colores, distribución y diseño responsive.
- `js/script.js`: menú móvil, año automático, botón volver arriba y navegación activa.
- `img/`: carpeta reservada para imágenes propias.

## Cómo ejecutarlo
1. Descomprime la carpeta.
2. Abre `index.html` en tu navegador.
3. Para trabajar cómodamente, abre la carpeta en Visual Studio Code.

## Personalización antes de publicar
- Sustituye el nombre, biografía, profesión y habilidades por información real.
- Reemplaza los proyectos de ejemplo por proyectos propios.
- Cambia `correo@ejemplo.com` por tu correo real en el enlace `mailto:`.
- Sustituye los enlaces de GitHub y LinkedIn por tus perfiles.
- Agrega una fotografía propia si deseas; la tarjeta con iniciales es un recurso temporal.
- Revisa los niveles visuales de habilidades: son ilustrativos y no deben presentarse como mediciones objetivas.

## Nota
El formulario de contacto no está implementado; el botón de correo abre el programa de correo del visitante mediante `mailto:`.
